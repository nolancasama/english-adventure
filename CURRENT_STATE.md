# Current State

## Status

Playable MVP complete and verified locally (2026-10-04). All 10 lessons play end to end at 320x640; progress survives reload; the app works offline after the first load. Not yet tested by a real child or on a physical Android device.

## What Exists

- Vite + React + TypeScript PWA (`vite-plugin-pwa`, Workbox precache, PNG + SVG icons). No backend; progress in localStorage (`mea.progress.v1`, versioned with migration).
- Content contract `src/content/types.ts`; data in `src/content/` (items, patterns, 10 lessons + chest milestone, pets). Review/Boss generated by `generate.ts` (weighted to missed/unseen items, shape-matched choices, abstract items excluded from picture questions).
- Activity registry `src/engine/activities.tsx`: listen-picture, picture-word, sentence-builder (tap tiles, lowercase display), speak (unscored).
- Screens in `src/App.tsx`: home road (measured SVG road), lesson flow + celebration, Boss "Quiz Monster", pets, parent view behind a 3-second hold, reset with two confirmations, back-button guard.
- Audio `src/audio/`: recorded-file manifest (empty) → Web Speech fallback; WebAudio SFX.

## How to Run

```bash
npm install
npm run dev          # local dev
npm run build && npm run preview
npm run typecheck
npm test             # 32 unit tests
npm run e2e          # full 10-lesson playthrough at 320x640 (Playwright)
npm run e2e:shots    # one PNG per screen into .tmp/shots/
```

## Known Issues

- Emoji are placeholders; art differs per platform. Replace via `Visual { kind: "image" }` without touching lessons.
- TTS voice quality/availability varies by device; no recorded audio yet.
- Japanese instruction speech uses ja-JP TTS only if the device has a Japanese voice.
- `start_url`/`scope` are `/`; hosting under a sub-path needs Vite `base` + manifest paths adjusted.
- The treasure chest sits beside the road rather than on it (cosmetic).
